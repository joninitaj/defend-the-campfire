# Defend the Campfire

A Vampire Survivors-style arena game. Keep the fire if you can. If it dies, you still fight.

## Play

Open `index.html` in a browser, or use the GitHub Pages link on this repo.

- **Enter** start
- **WASD** move
- **Space** dash
- **P** pause
- **F** fullscreen

Camp upgrades appear every 3 waves while the fire is still lit.

## CrazyGames

The HTML5 SDK v3 is included. Real banner and midgame ads run on CrazyGames. Locally you will see ad-slot placeholders and a short preview overlay.
